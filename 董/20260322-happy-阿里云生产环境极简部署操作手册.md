# Happy Coder 阿里云生产环境极简部署操作手册

这份文档记录了在阿里云 CentOS/Alibaba Linux 服务器上，从零开始部署 Happy Coder（端到端加密大模型终端）的**唯一正确路径**。
本手册已剔除所有容易踩坑的方案（如 PGLite、服务器端直接打包、明文模式等），请严格按照以下步骤执行。

## 前置条件
- 一台阿里云服务器（推荐至少 2核 4G）
- 两个已经解析到服务器 IP 的域名（例如：`app.yourdomain.com` 供前端使用，`api.yourdomain.com` 供后端使用）
- 服务器已安装 Node.js (v20+)、Yarn、Git

---

## 第一阶段：前端 Web 资源打包与部署

> **核心原则**：为了避免服务器内存溢出 (OOM)，必须在**本地 Mac 电脑**上完成打包，然后将静态文件上传至服务器。

### 1. 本地 Mac 打包
在你的 Mac 终端中执行：
```bash
cd /path/to/happy-main/packages/happy-app

# 确保没有任何环境变量干扰，执行纯净打包
yarn expo export -p web
```

### 2. 上传到阿里云服务器
将打包生成的 `dist` 文件夹上传到服务器的 `/var/www/happy-web` 目录下（不要放在用户目录如 `/home/admin` 下，会引起 403 权限问题）。

在阿里云服务器执行：
```bash
# 创建标准 Web 目录并设置权限
sudo mkdir -p /var/www/happy-web
sudo chown -R admin:admin /var/www/happy-web
```
将本地的 `dist/*` 内容全部复制到服务器的 `/var/www/happy-web/` 目录中。

## 第二阶段：后端原生 Postgres 数据库配置

> **核心原则**：必须放弃 PGLite，使用原生 PostgreSQL 数据库以保证 Prisma 兼容性。

### 1. 安装并启动 PostgreSQL
在阿里云服务器终端执行：
```bash
# 安装
sudo yum install -y postgresql-server postgresql-contrib

# 初始化
sudo postgresql-setup initdb

# 修改配置允许本地免密登录 (极其重要，防止提权密码报错)
sudo sed -i 's/ident/trust/g' /var/lib/pgsql/data/pg_hba.conf
sudo sed -i 's/peer/trust/g' /var/lib/pgsql/data/pg_hba.conf
sudo sed -i 's/md5/trust/g' /var/lib/pgsql/data/pg_hba.conf

# 启动并设置开机自启
sudo systemctl start postgresql
sudo systemctl enable postgresql
```

### 2. 创建数据库及用户
```bash
sudo su - root -c "psql -U postgres -c \"CREATE USER happy WITH PASSWORD 'happy2026';\""
sudo su - root -c "psql -U postgres -c \"CREATE DATABASE happy_db OWNER happy;\""
```

### 3. 初始化表结构
```bash
cd /home/admin/.openclaw/workspace/happy/

# 生成 Prisma 客户端
yarn workspace happy-server generate

# 使用 db push 强制同步表结构 (避开 migrate_lock 冲突)
DATABASE_URL="postgresql://happy:happy2026@localhost:5432/happy_db" yarn workspace happy-server prisma db push
```

## 第三阶段：后端 API 服务启动

> **核心原则**：使用纯净的 shell 脚本启动，避开 PM2 对 yarn 命令的错误解析。

### 1. 先确认 Redis

如果你准备在服务端环境变量里写入 `REDIS_URL=redis://127.0.0.1:6379`，那 Redis 必须先可用；否则 API 会启动失败并在 PM2 中反复重启。

```bash
sudo yum install -y redis || (sudo apt-get update && sudo apt-get install -y redis-server)
sudo systemctl enable redis || sudo systemctl enable redis-server
sudo systemctl restart redis || sudo systemctl restart redis-server
redis-cli -h 127.0.0.1 -p 6379 ping
```

### 2. 创建启动脚本
在服务器的 `happy` 根目录下执行：
```bash
cat << 'EOF' > start-server.sh
#!/bin/bash
cd /home/admin/.openclaw/workspace/happy/

# 基础目录配置
export DATA_DIR="./data"
export METRICS_ENABLED="false"

# 数据库连接
export DATABASE_URL="postgresql://happy:happy2026@localhost:5432/happy_db"
export REDIS_URL="redis://127.0.0.1:6379"

# 核心密钥 (此密码用于签发 Token，请妥善保管)
export HANDY_MASTER_SECRET="happy-master-secret-2026"

# 启动后端服务
exec yarn workspace happy-server start
EOF

# 赋予执行权限
chmod +x start-server.sh
```

### 3. 使用 PM2 挂载进程
```bash
# 全局安装 pm2 (如未安装)
npm install -g pm2

# 启动脚本
pm2 start ./start-server.sh --name happy-api

# 保存并设置开机自启
pm2 save
pm2 startup
```

## 第四阶段：Caddy 反向代理与 HTTPS 配置

> **核心原则**：Happy Coder 的端到端加密强依赖 Web Crypto API，必须在 HTTPS 环境下运行。

### 1. 安装 Caddy
```bash
sudo yum install -y yum-plugin-copr
sudo yum copr enable @caddy/caddy
sudo yum install -y caddy
```

### 2. 配置 Caddyfile
```bash
sudo vi /etc/caddy/Caddyfile
```
填入以下内容（请将域名替换为你自己的域名）：
```caddyfile
# 前端静态网站
app.yourdomain.com {
    root * /var/www/happy-web
    file_server
    try_files {path} /index.html
}

# 后端 API 代理
api.yourdomain.com {
    reverse_proxy localhost:3005
}
```

### 3. 启动 Caddy
```bash
sudo systemctl restart caddy
sudo systemctl enable caddy
```

## 第五阶段：客户端连接与使用

### 1. 网页端注册 (主设备)
打开 **Chrome 或 Edge 浏览器**（**警告：不要使用 Safari**，其 ITP 策略会拦截加解密 API 导致连接失败）。
访问 `https://app.yourdomain.com`，点击“创建账户”，系统会在本地生成密钥并自动登录。

### 2. 手机端访问与账号同步
因为 Happy 是端到端加密的，账号密钥只存在于你的 Mac 浏览器本地。如果你想在手机上也能看到一样的对话和终端，**不要在手机上点击“创建账户”**，而是需要把 Mac 上的密钥同步到手机。
如果在手机页面上找不到“导入账号”的入口，可以通过强行替换手机浏览器本地缓存的方式实现：
1. 在电脑浏览器里，点击 Happy 页面右上角的 **设置图标 (齿轮/头像)**，进入 **账户** 页面。
2. 找到 **备份 -> 密钥 (点击显示)**，点击它，复制显示出来的那长串字符串（这是你的私钥）。
3. 把这串私钥通过微信等发送到你的手机上。
4. 拿出手机，打开手机浏览器访问 `https://app.yourdomain.com`，点击**创建账户**（先随便创建一个空账号）。
5. 在手机浏览器里输入这行代码（通常需要利用书签执行 JavaScript，或者如果你会用手机的开发者工具）：
   `localStorage.setItem('happy-coder-secret', '你刚才复制的密钥字符串'); location.reload();`
6. 页面刷新后，手机端就会强行覆盖为 Mac 上的主账号，并同步所有会话和终端。

### 3. 本地 Mac 终端挂载与启动守护进程

当你的 Mac 重启，或者终端被不小心关掉后，网页端会显示“No active sessions”。此时需要重新将你的 Mac 挂载到云端。
**请务必严格按照以下目录和顺序执行：**

#### 第一步：进入项目根目录
打开 Mac 终端，必须先进入到 `happy-main` 的**根目录**，否则会报错 `Command "cli" not found`：
```bash
cd /Users/dongaiqiang/Documents/mycode/codes/00-chanpin/happy-main
```

#### 第二步：浏览器授权登录
在根目录下执行以下命令，向云端请求授权：
```bash
# 注意替换成你实际的云端 API 和 Web 域名
HAPPY_SERVER_URL=https://api.easycode-ai.xyz HAPPY_WEBAPP_URL=https://app.easycode-ai.xyz yarn cli auth login
```
执行后，终端会提示你选择验证方式：
1. 输入 `2` 选择 **"Web Browser"**。
2. 浏览器会自动弹出一个网页。
3. 在弹出的网页中点击 **"Approve（授权）"**。
4. 终端显示绿色的 `✔ Authentication successful` 即代表登录成功。

#### 第三步：启动守护进程 (Daemon)
登录成功后，**在同一个终端窗口，继续执行以下命令启动守护进程**：
```bash
HAPPY_SERVER_URL=https://api.easycode-ai.xyz yarn cli daemon start-sync
```

**⚠️ 极其重要：**
- 这条命令执行后，终端看起来会“卡住”或者只剩下一个光标在闪，**这是完全正常的**！因为它是一个后台守护进程，正在默默监听云端的指令。
- **千万不要按 Ctrl+C 或者关闭这个终端窗口！** 只要这个窗口开着，你在 `app.easycode-ai.xyz` 网页端左下角就会看到绿色的 "Connected"，就可以随时发送指令让这台 Mac 帮你写代码了。

---
**日常排障指令**
- 查看后端日志：`pm2 logs happy-api --lines 50`
- 重启后端服务：`pm2 restart happy-api --update-env`
- 本地终端连接失败（幽灵 Token）处理：在 Mac 上执行 `rm -rf ~/.happy/*`，清空浏览器缓存后，重新执行 auth login。
