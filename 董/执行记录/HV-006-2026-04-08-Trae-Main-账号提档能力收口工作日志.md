## 5. 本轮最终采用的提档承接方式

### 5.1 标准网络入口

- 方式：`POST /admin/upgrade`
- 适用场景：远端环境、已配置 `ADMIN_TOKEN` 的环境、需要走 HTTP 运维入口的场景

### 5.2 最小内部入口

- 方式：`yarn workspace happy-server admin:upgrade -- ...`
- 适用场景：本地主线联调、真机测试临时提档、内部排障快速解除低档位阻断

## 6. 使用方式沉淀

### 6.1 走接口调用

- 必要输入：
  - `accountId` 或 `username`
  - `tier`
  - 可选 `billingPeriod`
  - 可选 `status`
  - 可选 `endDate`
- 鉴权方式：
  - `x-admin-token: <ADMIN_TOKEN>`
  - 或 `Authorization: Bearer <ADMIN_TOKEN>`

### 6.2 走脚本调用

- 示例一：

```bash
yarn workspace happy-server admin:upgrade -- --account-id cmxxxx --tier pro --billing-period annual
```

- 示例二：

```bash
yarn workspace happy-server admin:upgrade -- --username alice --tier team --status active
```
