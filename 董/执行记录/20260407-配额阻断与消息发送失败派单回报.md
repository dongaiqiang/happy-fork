# 复现路径

- 条件 A：会话 `controller = mac` 且移动端继续发送消息
- 条件 B：会话 `handoffState = switching` 且移动端继续发送消息
- 步骤：
  1. 服务端 `/v3/sessions/:sessionId/messages` 返回 `409 / mobile-controller-required` 或 `409 / switching-in-progress`
  2. 修复前前端未把这两类错误视为不可重试
  3. pending outbox 留存
  4. App 若在 background / inactive 超过 30 秒，则用户看到 `Message failed to send in background after 30s. Please retry.`

# 修复动作

- 将 `409 / mobile-controller-required` 标记为不可重试，并给出可操作提示
- 将 `409 / switching-in-progress` 标记为不可重试，并给出可操作提示
- 在命中上述 409 时主动刷新 sessions，尽快同步 controller / handoffState
- 补充单测覆盖两类 409 场景
