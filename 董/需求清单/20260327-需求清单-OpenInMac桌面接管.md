# 20260327 需求清单：Open in Mac（桌面接管）

## 1. 文档目的

本需求文档聚焦一个产品能力：  
手机端会话可在 Mac 本地 Claude Code 一键接管继续（Open in Mac）。

---

## 2. 业务背景

当前痛点：会话由手机端远程控制后，缺少“回到本地 Claude Code 继续同一会话”的明确产品能力。

---

## 3. 核心需求：Open in Mac / Open in Claude Code（桌面接管）

## 3.1 需求描述

当会话在手机端进行中时，用户希望可在 Mac 本地直接打开并接管同一会话，继续在本地 Claude Code 中工作，而非新建会话。

## 3.2 用户价值

1. 支持“移动端处理 + 桌面端深度开发”无缝切换  
2. 减少上下文丢失与重复输入  
3. 形成真实双端协同工作流

## 3.3 功能定义（产品语义）

新增动作：`Open in Mac` / `Open in Claude Code`

行为定义：

1. 在手机端会话详情页点击该动作  
2. 向目标机器下发“本地接管”请求  
3. 在 Mac 侧以 `claude --resume <claudeSessionId>` 打开对应会话  
4. 成功后会话控制权切回桌面端，手机端进入观察态或只读态

## 3.4 前置条件

1. 目标机器在线  
2. daemon 正常运行  
3. 会话存在可恢复的 `claudeSessionId`  
4. 本地环境具备可执行 Claude Code 能力

## 3.5 验收标准

1. 手机端点击“Open in Mac”后，Mac 可打开同一会话并继续对话  
2. 新输入可继承既有上下文，非新开空会话  
3. 失败场景有明确提示（离线、权限、会话不存在）

## 3.6 非目标（本期不做）

1. 不做跨端同时编辑冲突解决（并发输入仲裁）  
2. 不做多设备抢占策略细化  
3. 不做历史 UI 消息自动拼接迁移

---
