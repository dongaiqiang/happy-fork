### 2.3 数据库 Schema

**位置：** `packages/happy-server/prisma/schema.prisma`

**已定义模型：**

```prisma
model SubscriptionPlan {
    id           String   @id @default(cuid())
    accountId    String   @unique
    tier         String   // "free" | "student" | "pro" | "team" | "enterprise"
    status       String   // "active" | "cancelled" | "expired"
    tokensLimit  Int      // 每月 tokens 限额
    dailyLimit   Int      // 每日 tokens 限额
    rateLimit    Int      // 每分钟请求数限制
    storageLimit BigInt   // 存储限额 (bytes)
    startDate    DateTime @default(now())
    endDate      DateTime?
}

model DailyUsage {
    id          String   @id @default(cuid())
    accountId   String
    date        String   // 格式："YYYY-MM-DD"
    tokensUsed  Int      @default(0)
    requests    Int      @default(0)
    @@unique([accountId, date])
}

model UsageReport {
    // Session 级用量报告
    accountId   String
    sessionId   String
    key         String   // session:${sessionId}:${date}
    data        Json     // { tokens: { total }, cost: { total } }
    @@unique([accountId, sessionId, key])
}
```

## 7. 风险点

### 7.1 支付合规风险

- 中国大陆地区需要 ICP 许可证 + 支付牌照合作
- 虚拟商品税收政策需确认
- 自动续费需要明确告知用户

### 7.2 RevenueCat 依赖风险

- RevenueCat 收取 1-4.9% 收入分成
- 国内访问速度可能较慢
- 需要备选方案（如直接对接 stripe）

### 7.3 配额计算风险

- Token 估算可能与实际 API 计费不一致
- 不同模型（Claude/Codex/Gemini）成本不同
- 需要考虑「成本加成」定价策略
