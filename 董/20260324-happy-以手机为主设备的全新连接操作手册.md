# 📱 Happy Coder：以手机为主设备的全新连接与排坑操作手册

**文档创建日期：** 2026年03月24日

本文档记录了在 Happy Coder 架构下，如何抛弃基于网页端的旧模式，转而建立“以手机端为绝对主控，Mac 作为纯算力后台节点”的全新连接模式。
**特别注意：** 开源版本存在“默认连接原作者服务器”的深坑，本文档包含了完整的排坑与清理流程。

---

## 一、 核心架构认知转变 (Mobile-First)

在过去的模式中，我们习惯于在电脑网页端生成密钥，然后用手机去“恢复账户”。这会导致底层会话进程与浏览器强绑定，一旦电脑终端意外关闭，手机端的会话就会变成“僵尸状态”（发消息无响应）。

**现在的正确模式：**
1. **手机端**：作为唯一的主控中心，负责生成和持有最高权限的端到端加密密钥。
2. **Mac 电脑**：作为一个被控节点（Agent），向云端申请认主，并在后台默默运行守护进程。
3. **阿里云服务器**：作为中转邮局，仅负责搬运加密数据包。

---

## 二、 完整操作步骤（从零开始）

### 1. 清理 Mac 的历史残留（非常重要）
为了防止旧的网页端配置干扰，必须先将 Mac 端彻底“洗脑”。
打开 Mac 终端，执行以下命令：

```bash
# 1. 强制停止所有正在运行的进程
# 如果终端卡在运行状态，请按 Ctrl + C

# 2. 清理全局隐藏配置文件（彻底抹除历史记忆）
rm -rf ~/.happy

# 3. 进入项目根目录（后续所有 yarn 命令必须在此目录下执行）
cd /Users/dongaiqiang/Documents/mycode/codes/00-chanpin/happy-main

# 4. 清除 CLI 的登录状态凭证
yarn cli auth logout
```
*(预期结果：提示 `Not currently authenticated` 或类似成功清理的提示)*

### 2. 初始化手机主控端与【跨服排坑】
因为您刚安装/重装了手机 App，**千万不要直接点创建账号或恢复账号**，必须先修改服务器地址！

1. **修改服务器地址（关键排坑）：**
   * 打开刚安装好的 Happy App（停留在欢迎界面）。
   * 注意看屏幕**右上角**，点击那个“服务器”形状的小图标。
   * 在弹出的输入框中，将原作者的默认地址修改为您自己的阿里云中转地址：
     👉 `https://api.easycode-ai.xyz`
   * 点击保存。
   > **⚠️ 避坑指南：** 如果不改这一步，手机会连接到原作者的默认服务器。后续扫码时，虽然手机会提示“成功”，但 Mac 端会一直卡在 `Waiting for authentication..`（因为它们根本不在同一个服务器上）。

2. **生成手机主密钥：**
   * 地址修改完成后，回到欢迎界面。
   * 点击 **“创建账户 (Create Account)”**。
   * 此时手机已在本地生成了最高权限的全新加密密钥，正式成为主控中心。

### 3. Mac 申请“认主”并生成二维码
回到 Mac 终端，继续在项目根目录下执行：

```bash
# 1. 确保仍在项目根目录
cd /Users/dongaiqiang/Documents/mycode/codes/00-chanpin/happy-main

# 2. 告诉 Mac 连接您的阿里云服务器，并请求登录
export HAPPY_SERVER_URL="https://api.easycode-ai.xyz"
yarn cli auth login
```

* 终端会提示 `How would you like to authenticate?`。
* 使用键盘上下方向键，选择 **`Mobile App`** 并回车。
* 此时终端会打印出一个巨大的**二维码**，并显示 `Waiting for authentication..`。

### 4. 手机扫码，下发密钥
1. 拿起手机 App，进入底部的 **设置 (Settings)** -> **账户 (Account)** -> **链接新设备 (Link New Device)**。
2. 扫描 Mac 终端上的二维码。
3. **验证成功：** 手机端会提示“成功”；同时，Mac 终端会瞬间结束等待，打印出 `✓ Authentication successful` 以及一串 `Machine ID`。
*(至此，Mac 正式成为手机的专属被控节点)*

### 5. 在 Mac 上启动“守护进程” (Agent)
认证成功后，我们需要让 Mac 作为一个后台服务默默运行，随时等待手机的指令。

```bash
# 1. 确保仍在项目根目录
cd /Users/dongaiqiang/Documents/mycode/codes/00-chanpin/happy-main

# 2. 启动守护进程并保持与阿里云的同步连接
export HAPPY_SERVER_URL="https://api.easycode-ai.xyz"
yarn cli daemon start-sync
```
*(此时终端会显示 `Daemon started` 等日志。**请保持这个终端窗口不要关闭**，让它一直在后台运行)*

### 6. 开始遥控！
1. 回到手机 App 的首页（收件箱）。
2. 点击右上角的 **加号 `+`** 新建一个会话 (New Session)。
3. 在输入框发送指令，例如：“你好”。
4. 指令会瞬间推送到 Mac 端，您可以看到 Mac 终端开始疯狂滚动日志（唤醒 Claude 执行任务），并将结果实时反馈回手机屏幕！
