# 2026-03-26 后台配置执行清单（语音 ASR）

## 0. 目标

- 目标：让 iOS 端“语音输入 -> 实时转文字 -> 可发送”稳定可用。
- 当前策略：仅使用后端流式 ASR，不启用原生 SDK 路径。

## 1. 环境准备清单

- [ ] 在后端运行环境配置 `IFLYTEK_APPID`
- [ ] 在后端运行环境配置 `IFLYTEK_API_KEY`
- [ ] 在后端运行环境配置 `IFLYTEK_API_SECRET`
- [ ] 确认三项变量在 `happy-server` 进程可读取

## 2. 启动清单（按顺序）

- [ ] 根目录执行：`yarn install`
- [ ] 后端目录执行：`packages/happy-server` -> `yarn dev`
- [ ] 前端目录执行：`packages/happy-app` -> `npx expo start --dev-client -c`
- [ ] 如需重装 iOS：`packages/happy-app` -> `npx expo run:ios --device --no-install`

## 3. 前端模式清单

- [ ] 设置页确认 `voiceInputMode = streaming_asr`
- [ ] 输入区确认只有单语音入口（不出现双按钮）
- [ ] 语音按钮状态正常切换（mic -> stop -> send）

## 4. 联调验证清单

- [ ] 点击开始后，后端打印“连接讯飞成功”
- [ ] 后端持续打印 `讯飞返回 (sn..., pgs...)`
- [ ] 前端持续打印 `收到后端发来的 asr_text`
- [ ] 输入框文本连续增长，不是只出一个字
- [ ] 点击停止后文本保留
- [ ] 点击发送后消息写入成功（接口 200）

## 5. 异常排查清单

### A. 无识别结果

- [ ] 检查后端三项密钥是否存在
- [ ] 检查后端是否打印 `asr_start` 与连接成功日志
- [ ] 检查前端是否真的在 `streaming_asr`

### B. 只出一个字

- [ ] 检查输入区是否仍是单组件路径（未被切回双入口）
- [ ] 检查后端是否持续返回 `sn:2,3...`
- [ ] 检查前端是否持续收到 `asr_text`

### C. 发送失败

- [ ] 检查 `/v3/sessions/.../messages` 是否 200
- [ ] 检查鉴权 token 是否有效

## 6. 验收标准

- [ ] 连续说一句 5~10 字，输入框连续更新
- [ ] 连续执行 3 次“开始-停止-发送”都成功
- [ ] 后端无阻断性错误日志（允许常规 warning）

## 7. 回归建议

- [ ] 每次改动 `useCustomASR` 或 `asrHandler` 后都跑一次本清单
- [ ] 每次改动输入区按钮逻辑后重点验证“单入口不切组件”
