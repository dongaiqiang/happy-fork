## 2. Step 1：停掉所有旧服务并清理旧密钥（双端核弹级清理）

**操作目的**：杀掉所有僵尸进程，并彻底清空 Mac 端和服务器端由于历史残留导致的脏密钥数据。

**1. 停掉旧进程与旧守护进程（推荐一键版，直接复制）**（任意目录执行）：

```bash
cd /Users/dongaiqiang/Documents/mycode/codes/00-chanpin/happy-main
pkill -f "daemon start-sync" || true
pkill -f "yarn workspace happy-server dev" || true
pkill -f "expo start" || true

for p in 8081 3005 5432 9090 9091; do
  lsof -ti tcp:$p | xargs kill -9 2>/dev/null || true
done

unset HAPPY_HOME_DIR
yarn cli daemon stop || true

export HAPPY_HOME_DIR=$HOME/.happy-rebind-20260327
yarn cli daemon stop || true

ps aux | grep -E "daemon start-sync|happy-server dev|expo start" | grep -v grep || echo "OK: 旧进程都停掉了"
```

- 如果你看到 `OK: 旧进程都停掉了`，说明停干净了。
- 如果没有看到这行，就把终端输出截图保存，继续按下文排查。
- 之前出现 `kill: illegal pid` 的原因是旧命令一次拿到多行 pid 后直接传给 `kill`，导致参数解析错误。上面这一版不会触发这个问题。

**2. 清理 Mac 端本地旧密钥缓存**（在项目根目录执行）：

```bash
rm -rf ~/.happy
rm -rf ~/.happy-rebind-20260327
```

**3. 清理手机端缓存（极其重要）**：
- 如果你之前遇到了 `Machine encryption not found` 错误，**仅仅把 App 从后台划掉是没用的**。
- **你必须在手机上卸载该 App（Dev Client）并重新安装**，或者在 App 内找到退出登录/注销账户的选项彻底注销，以销毁手机本地失效的主密钥。

## 4. Step 3：启动 Docker（手动）
- 先执行（自动打开 Docker Desktop）：

```bash
open -a Docker
```

- 再执行（阻塞等待 Docker daemon 就绪）：

```bash
until docker ps >/dev/null 2>&1; do
  echo "等待 Docker daemon 启动..."
  sleep 2
done
docker ps
```

- 如果上一步仍失败，再执行（修正 Docker context）：

```bash
docker context use desktop-linux
docker ps
```

- **成功标准**：`docker ps` 能正常返回列表，不再出现 `Cannot connect to the Docker daemon`。
- **注意**：满足成功标准后，才可继续下一步。

## 7. Step 6：手机端全新初始化与加载前端
1. 打开手机 App（或者用手机相机扫描**终端 B** 的二维码打开 Dev Client）。
2. 分两种情况：

## 8. Step 7：执行扫码授权与启动守护进程（终端 C）

**操作目的**：让新初始化的手机端与 Mac 端的 CLI 建立全新的加密绑定关系。

- 在项目根目录新建终端（终端 C）执行：

```bash
cd /Users/dongaiqiang/Documents/mycode/codes/00-chanpin/happy-main

# 注入正确的环境变量并指定一个干净的配置目录
export HAPPY_SERVER_URL=http://192.168.10.114:3005
export HAPPY_HOME_DIR=$HOME/.happy-rebind-20260327

# 发起认证请求
yarn cli auth login --force
```

1. 终端提示选择认证方式时，用键盘方向键选择 **Mobile** 并回车。
2. 终端会打印出一个由 ASCII 字符拼成的**巨大二维码**。
3. 拿起手机，进入 App 的**设置页面**，点击**扫码**，扫描这个巨大二维码。
4. 扫码成功后，Mac 终端会显示 `✓ Authentication successful` 以及新的 `Machine ID`。

- 紧接着在同一个终端（终端 C）执行：

```bash
# 必须带上同样的环境变量
export HAPPY_SERVER_URL=http://192.168.10.114:3005
export HAPPY_HOME_DIR=$HOME/.happy-rebind-20260327

yarn cli daemon start-sync
```
- **注意**：命令执行后会“卡住”不输出新内容，这是正常的，说明守护进程已在前台持续监听。终端 C 保持运行，不要关闭。
- **补充**：`yarn cli daemon start-sync` 本来就是常驻命令，看起来像“卡住”，其实就是正在工作，不是异常。

## 9. Step 8：最终验证与解决首次竞态报错
1. 在手机 App 里，进入**设置里的连接状态页面**，确认状态变成了 **“已连接”（绿点）**。
2. **已知竞态现象提醒**：如果你在刚刚扫码成功的那一瞬间，App 底部弹出了一次红底错误 `Machine encryption not found`，**请不要慌张，也不要再去做重置操作**。
   - **原因**：这是因为服务器推送的实时状态比手机本地密钥初始化稍微快了一丁点。
   - **解决办法**：只需将 App 从手机后台完全划掉（杀掉进程），然后重新打开 App。系统会进行一次完整的冷启动，错误将永远消失，各项功能（对话、语音等）将恢复正常。

## 10. 快速检查端口（排错备用）
如果在日常开发中突然断连，可开一个新终端执行以下命令检查存活状态：

```bash
for p in 8081 3005 5432 9091; do
  ids=$(lsof -ti tcp:$p)
  if [ -n "$ids" ]; then
    echo "$p OK => $ids"
  else
    echo "$p MISSING"
  fi
done
```

## 11. 常见错误速查
- `Cannot connect to the Docker daemon`：Docker 未启动。请参考 Step 3。
- `P1001 localhost:5432`：数据库未启动或端口不通。请检查 Docker 和 `yarn workspace happy-server db`。
- `Machine encryption not found`：双端密钥不同步。请严格按照本 SOP 的 Step 1 至 Step 8 **从头到尾完整执行一次**（切记要卸载手机 App 并清理数据库）。
